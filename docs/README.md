# Documentation

| Audience | Entry point | Topics |
| --- | --- | --- |
| Application authors and operators using oden or odenctl | [User documentation](user/README.md) | Installation, Rust/MoonBit apps, configuration, deployment, and operations |
| Contributors changing oden or odenctl itself | [Developer documentation](developer/README.md) | Architecture, WIT/SDK internals, conformance tests, benchmarks, and proposals |

Writing an application, using the SDK, or running `oden test` belongs to the user
guides. Changing the runtime, SDK implementation, control plane, or repository
tests belongs to the developer guides. Contribution setup and the PR workflow
are in [CONTRIBUTION.md](../CONTRIBUTION.md).
